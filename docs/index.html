Overview

Enshrouded Server Manager is a single dbghelp.dll that loads with your Enshrouded dedicated server. It runs inside the server and holds the secure WebSocket to Takaro itself. Only the server needs it; players join as usual.

Player EventsJoin, leave, chat, deaths and kills tracked in Takaro in real time.
Admin ActionsBroadcast, give items, teleport, kick/ban/unban, read inventory & location.
Character LevelsEach player's character name and level, ready for Takaro modules through the levels command.
Discord ChatGame chat to Discord and Discord back into game chat through Takaro modules.
One DLL does it allCopy one file next to the server and paste your Takaro token.

Supported Versions

Supports Enshrouded 1.0 (game build 1267041) and the earlier build 1024233, on Windows and under Wine/Proton on Linux. It is a community connector, with its source in gettakaro/connectors; every new version is published to this page's releases automatically.

Install

  1. Download takaro-enshrouded-plugin.zip from the latest release.
  2. Stop the server and copy dbghelp.dll from the zip next to enshrouded_server.exe: 
    enshrouded_server.exe
dbghelp.dll                  (the mod)
takaro\plugin.json            (created at the first start — edit this)
  3. On Linux under Wine/Proton, set WINEDLLOVERRIDES=dbghelp=n,b so the server loads the mod.

Configure

  1. In Takaro: Game servers → Create new game server → Generic, copy your registration token. The server appears in Takaro by itself when it connects.
  2. Start the server once; it creates takaro\plugin.json. Paste your token, put your server's name into identityToken and save — the mod connects within a few seconds:
{
  "registrationToken": "paste-your-token-here",
  "identityToken": "name-your-server"
}

Takaro creates the game server under that name and recognizes it by it from then on, so pick a name no other server in your Takaro uses and keep it.

Start & Verify

  1. Start the server. dbghelp.dll loads with it automatically.
  2. takaro\plugin.log shows connected to Takaro as "<name>".
  3. The server shows online in the Takaro dashboard within seconds.
  4. Have a player join & chat — player-connected and chat-message appear in Takaro.

Actions Takaro Can Run

ActionWhat it does
getPlayers / getPlayerLocation / getPlayerInventoryRead who is online, where they are and what they carry.
sendMessageBroadcast to game chat as a notice, styled like the game's own join messages.
giveItem / teleportPlayerItem delivery (shop, rewards) and teleports.
kickPlayer / banPlayer / unbanPlayer / listBansModeration by SteamID, Admin-group players included.
listItems / listEntitiesItem and creature catalogue with in-game English names.
executeConsoleCommandBuilt-in commands: players, say, whisper, give, item, teleport, kick, save-and-shutdown.

Game Updates

Everything that changes between game builds lives in takaro\enshrouded-gamedata.json, one section per build. The log prints game build: <n> at start. After a game update the mod works out the new build's section from the game itself, saves it to that file with the note derived automatically and uses it, so the same DLL keeps working. Any feature it could not set up shows as degraded in Takaro while the rest keeps running, and a newer release brings it back.
